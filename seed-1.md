I want to build a databricks app that provides a coordination front end for business users and engineers to be able to communicate changes needed for existing and new metric views that define the main KPIs for each business area. App users don't need to write to the unity catalog, but will instead read existing metric views published to the UC and they can create new drafts for metric views on the front end without understanding the engineering metric view SQL/yaml syntax. The goal is to make this application for collaboration, discovery and development of existing future metric views that are relevant to changing business areas and priorities.
