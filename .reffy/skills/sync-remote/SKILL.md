## Shared FDE Boundary

Personal remote-workspace publishing is intentionally outside this repository's shared FDE workflow.

- Do not configure or invoke personal remote-workspace features for FDE workstation setup, planning, validation, shared references, or source-code synchronization.
- Use the repository-local `.reffy/` planning files and the explicitly selected GitHub source repository for shared FDE work.
- Project owners who use personal remote-workspace features must keep their setup and operating guidance outside this repository.
